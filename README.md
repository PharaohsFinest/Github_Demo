<h3>Important Git Commands</h3>
<ul>
<li>git clone - Clones a repositroy</li>
<li>git fetch downloads updates from a remote
repository, but does not merge them with the local
repository</li>
<li>git pull - Downloads all the newest updates from your remote repository to your local repository and merges them</li>
<li>git push - Uploads the latest updates from your local repositroy to the remote repository</li>
</ul>
